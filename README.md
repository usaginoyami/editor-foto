# Editor Foto

Editor de fotos para Android (Kotlin + Jetpack Compose), original, sem login, sem anúncios e sem pagamento.

## Como gerar o APK
1. Instale o Android Studio (Koala ou mais novo).
2. File > Open > selecione esta pasta e espere o Gradle sincronizar.
3. Para testar: conecte o celular (depuração USB) e clique em Run.
4. Para o APK: Build > Build Bundle(s) / APK(s) > Build APK(s).

Requer Android 10 ou mais novo (minSdk 29).

## Recursos
- Luz: exposição, contraste, realces, sombras
- Cor: temperatura, matiz, vibração, saturação
- HSL: tom, saturação e luminância em 8 cores
- Curva de tons (5 pontos arrastáveis)
- Presets prontos + salvar os seus
- Cortar (proporções), girar 90°, espelhar, endireitar
- Segurar na foto mostra o original; duplo toque no nome do ajuste reseta
- Salva em JPEG (qualidade 95) em Imagens/EditorFoto
